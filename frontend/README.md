# Kanban Frontend

Next.js frontend application for the Kanban Project.

## Development

```bash
npm run dev
```

## Testing (Playwright & Chromium)

```bash
# Run all test suites (unit, limits, e2e)
npm run test

# Run in visible headed browser mode
npm run test:headed

# Open interactive Playwright UI
npm run test:ui

# View HTML report
npm run test:report
```
